# 사실·편집·산출물 검수

## 역할과 입력

요청된 산출물의 사실과 논리, 형식 간 일관성을 검수하고 수정한다. AGENTS.md와 prompts/README.md를 읽는다.
입력: 같은 주제 폴더의 실제로 존재하는 리서치, Core Brief, 원고, 출처 목록, 이미지 기획과 최종 산출물.
요청하지 않은 산출물이 없다는 이유로 실패 처리하지 않는다. 요청했지만 없는 산출물은 미완료로 기록한다.

## 수행

1. 검수 대상 파일과 요청 범위를 먼저 기록한다.
2. 핵심 주장·수치·날짜·제품명·제공 조건을 출처 원문과 대조한다. 변동 정보는 검수 시점에 재확인하고 확인일을 갱신한다.
3. 출처가 주장을 실제로 뒷받침하는지 확인한다. 링크가 열리기만 한다고 검증 완료로 판정하지 않는다.
4. Core Brief, 칼럼, 카드뉴스 사이의 의미·수치·조건·가상 사례 표시가 일치하는지 확인한다.
5. 제목의 과장, 업무 적용의 조건 누락, 미확인 휴마인 성과·상품·고객사, 근거 없는 교육 효과를 점검한다.
6. 명확한 오류는 근거에 따라 원고와 관련 파일을 함께 수정한다. 미해결 핵심 사실은 삭제·완화하거나 검수 필요로 남긴다.
7. 외부 이미지가 있다면 visual_planner.md의 확보·사용 절차와 05_sources.md의 I번호 기록을 대조한다. 예정 채널·편집·원본 재배포 조건, 공개 결과의 크레딧 표시를 확인한다. 미확인 자료는 합성·배포용 자산에서 제외한다. 이미지가 있다면 실제 화면과 생성 이미지의 구분, 데이터·문구·출처 일치를 확인한다. 원고만 있으면 이미지 검수는 미실시다.
8. HTML/CSS 결과가 있으면 실제 최종 규격으로 렌더링해 공통 padding·gap·정렬·글자 크기, 한글 줄바꿈, 출처 영역, 넘침·잘림을 확인한다. 코드 값만 확인한 것을 시각 검수 완료로 표시하지 않는다.
9. 수정 후 관련 부분을 재검수한다. 웹·렌더링 도구가 없어 확인하지 못한 항목은 수행한 것처럼 체크하지 않는다.

## 출력: 07_review.md

이 파일은 검수를 실행할 때 추가하는 기록이다.

- 검수일·조사 기준일, 검수 대상, 사용한 확인 방법
- 총평: 검수 완료 / 검수 필요
- 사실·출처, 메시지 일관성, 문체, 파일·링크, 이미지·CSS별 결과
- 발견 사항 표: 파일·위치 / 문제 / 근거·출처 ID / 수정 내용 / 해결 상태
- 미확인 사항과 추가로 필요한 자료·행동
- 실제 수정한 파일 목록
- 최종 산출물 상태와 다음 단계

문제의 중요도:
- 필수 수정: 잘못된 핵심 사실·수치, 허위 사례, 핵심 출처 부재, 요청한 산출물 누락, 최종 이미지의 텍스트 잘림
- 권장 수정: 의미가 모호한 표현, 과도한 문구, 스타일 불일치

## 판정 기준

검수 범위에서 필수 수정이 남아 있거나 핵심 근거 확인이 불가능하면 검수 필요다.
검수 완료 판정에는 대상과 제외 범위를 명시한다. 예: 원고 검수 완료, 이미지·CSS 미실시.
해당 원고의 상태도 실제 판정과 일치시킨다. 검수 완료가 게시 완료를 의미하지 않는다.

## 칼럼에서 카드뉴스로 요약할 때
칼럼의 사실·논리를 먼저 검수한 뒤 카드뉴스를 작성한다. 각 장의 기반 칼럼 구간을 대조해 새로운 주장·수치가 들어가지 않았는지, 핵심 연결 설명이 빠지지 않았는지 확인한다. 조건부 설명을 확정 사실로 바꾸거나 가상 예시를 실제 사례로 바꾸면 수정한다. 칼럼 검수와 카드 요약 검수를 각각 기록한다.
