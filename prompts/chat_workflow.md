# 현재 대화에서 콘텐츠와 이미지 제작

이 흐름은 Codex가 저장소와 현재 대화의 도구를 사용한다. Python에서 ChatGPT 세션을 호출하지 않는다. 별도 OPENAI_API_KEY는 필요하지 않으며, 이미지 도구의 사용 가능 여부와 이용 한도는 현재 환경에 따른다.

## 실행

1. AGENTS.md, prompts/README.md, 필요한 양식·가이드를 읽는다. 주제·기간·요청 형식을 확인한다. 기간 미지정이면 조사 기준일 포함 최근 7일을 적용하고 기록한다.
2. 새 주제면 `generate_content.py`로 준비한다. 이미지 생성까지 요청받았다면 `--images chat`, 기획까지만이면 `--images plan`을 사용한다. 기존 폴더는 다시 생성하지 않고 사용자 수정 내용을 보존하며 이어 쓴다.
3. 현재 대화의 웹 도구로 원문을 확인하고 리서치·출처 → Core Brief → 요청된 원고 → 이미지 기획을 실제 파일에 작성한다. 원고 작성에 write_content.py의 API 실행은 필요하지 않다.
4. fact_check.md에 따라 사실·내용 검수를 수행한다. 이미지 생성 요청이 있으면 아래 단계까지 진행한다.

## 이미지 생성과 파일 연결

- visual_planner.md를 적용해 `06_image_prompts.md`를 작성한다. 생성할 자산만 `image_plan.json`에도 기록한다. 실제 화면이나 수치 차트를 생성 일러스트로 대체하지 않는다.
- JSON 형식: `{"assets":[{"id":"hero","prompt":"완성된 이미지 생성 지시문"}]}`. ID는 소문자 영문·숫자·하이픈을 사용한다. 기획 내용과 JSON을 일치시킨다.
- `python3 scripts/generate_images.py contents/주제-폴더`로 대화 도구용 요청을 확인한다. 기본 최대 4개이며 더 필요하면 `--max-images`를 지정한다. 이 명령은 이미지 생성 자체를 실행하지 않는다.
- 현재 대화의 이미지 생성 도구를 사용한다. 관련 이미지 생성 스킬이 있으면 따른다. 한국어 본문·로고는 별도 합성하므로 배경 이미지에는 넣지 않는다. 4:5 카드와 레이아웃별 텍스트 영역을 고려한다.
- 실제 결과를 확인하고 접근 가능한 이미지 파일을 `images/자산-id.png` 등에 저장한다. 실제 파일 형식에 맞는 확장자를 유지한다. 기존 파일을 덮어쓰지 않고 새 ID를 쓴다. 결과가 대화에만 표시되고 로컬로 옮길 수 없으면 **이미지 생성 완료 / 저장·합성 미완료**로 구분한다. 경로나 다운로드 URL을 추측하지 않는다.
- 카드의 `이미지 경로`에 실제 파일의 상대 경로를 기록한다. 칼럼용 이미지면 해당 위치에 Markdown 이미지 참조와 대체 텍스트를 넣는다. `06_image_prompts.md`의 실제 경로와 제작 상태를 갱신한다.
- 도구가 없거나 실패하면 이유와 미완료 단계를 기록한다. 별도 유료 API로 자동 전환하지 않는다.

## 합성과 완료 보고

카드 원고와 이미지가 연결되면 `python3 scripts/build_cardnews.py contents/주제-폴더`로 HTML을 생성한다. 최종 카드 PNG 요청이 있을 때는 렌더링 환경을 확인하고 `--png`를 사용한다. 배경 이미지 생성과 최종 카드 PNG 출력은 별개다.

`07_review.md`에 사실·내용 검수, 이미지 생성·저장, HTML/PNG 출력 상태를 각각 기록한다. 줄바꿈·넘침 검수는 계속 보류하며 통과로 표시하지 않는다. 외부 게시는 수행하지 않는다.
