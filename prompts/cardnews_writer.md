# 카드뉴스 원고 작성

## 역할과 입력

Core Brief를 한 장에 하나의 메시지가 담긴 카드뉴스로 재구성한다. AGENTS.md와 prompts/README.md를 읽는다.
필수 입력: 02_core_brief.md, 01_research.md, 05_sources.md. 같은 주제 칼럼이 있으면 일관성을 확인한다.
선택 입력: 장수, 채널, 비율·출력 크기, 장별 문구 분량.
templates/cardnews_template.md, style/humine_content_guide.md, style/의 시각 가이드가 실제로 있으면 적용한다.

## 수행

1. 사용자가 정한 장수와 규격을 우선한다. 없으면 다음 8장 구성을 작업 기본안으로 사용하고 가정임을 명시한다. 주제에 따라 조정 이유를 기록한다.
   1. 표지: 독자의 관심을 끄는 핵심 질문 또는 변화
   2. Trend: 무엇이 달라졌는가?
   3. Why: 왜 지금 중요한가?
   4. Work: 기존 업무와 바뀐 업무
   5. Work: 구체적인 활용 장면과 사람의 검토
   6. Skill: 필요한 역량
   7. Education: 학습 방향과 실습 제안
   8. 마무리: 요약과 다음 행동
2. 한 장에 주장 하나를 둔다. 칼럼의 문단을 잘라 붙이지 않는다.
3. 장마다 제목 1개와 짧은 본문 1~3문장을 기본으로 한다. 필요한 조건·한계는 생략하지 말고 장을 나누거나 문구를 줄인다.
4. 주요 사실에 출처 ID를 연결한다. 본문용 짧은 출처와 전체 링크 목록을 함께 준비한다.
5. 문구가 길면 핵심을 다시 쓰거나 장을 나눈다. 글자 크기 축소나 제각각의 padding으로 해결하지 않는다.

## 출력: 04_cardnews.md

상단: 작성일, 조사 기준일, 상태, 기반 Core Brief 경로, 총 장수, 채널·규격(미정이면 미정), 적용한 가정.

각 장은 다음 항목을 포함한다.
- 장 번호 / 역할
- 핵심 메시지
- 제목
- 본문
- 보조 문구·조건·한계(필요 시)
- 시각 자료 지시: 개념도/실제 화면/사진/타이포그래피 중 목적에 맞게 지정
- 장별 시각 자산 ID와 확보 방식: 자료 확보 / 내장 생성 / 도식 제작. 각 장에 독립된 시각 자료를 기획하고 상세는 06_image_prompts.md에 기록한다. 이미지 경로는 실제 파일 확보 후에만 연결한다.
- 레이아웃 유형: cover / gradient / split / overlay / cta 중 선택. 표지는 cover, 마무리는 cta를 기본으로 하고 본문은 정보량에 맞게 선택
- 관련 출처 ID와 화면에 표시할 짧은 출처

마지막에는 전체 출처 링크와 편집 메모를 별도 구역으로 기록한다.
가상 업무 예시는 실제 사례처럼 표현하지 않는다. 확인되지 않은 교육 상품·고객사·성과·CTA 링크를 만들지 않는다.

## 스타일 연결

사용자가 제공한 5종 참고 레이아웃을 따른다. 5종은 틀의 종류이며 전체 장수를 5장으로 제한하는 의미가 아니다.
장별 CSS를 원고에 임의로 넣지 않는다. style/cardnews.css와 style/humine_visual_guide.md의 공통 토큰·텍스트 위치를 따른다. 제목·본문은 이미지와 분리해 배치하고 이미지에 맞춰 임의로 이동하지 않는다.
스타일 파일이 없으면 레이아웃 역할과 정보 위계만 지정하고 CSS 적용 완료로 보고하지 않는다.

## 완료 기준

전체 흐름에서 Trend → Work → Skill → Education이 이어지고 각 장을 단독으로 읽어도 오해가 없어야 한다.
원고 완료는 최종 이미지 완료가 아니다. 상태를 초안으로 두고 fact_check.md 및 visual_planner.md에 넘긴다.
