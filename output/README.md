# 결과물 전용 폴더

기획·원고·출처·검수 기록은 ../contents/에서 관리합니다. 이 폴더에는 주제별 실행 결과를 저장하며 과거 버전을 덮어쓰지 않습니다.

- `주제명/build-실행시각/index.html`: 전체 카드 보기
- `html/주제폴더명-card-01.html`: 장별 HTML
- `png/주제폴더명-card-01.png`: --png 요청 시에만 생성하는 카드 이미지
- `assets/`: 이번 실행에 실제 사용한 배경 원본 (중복 제거)
- `manifest.json`: 원고 해시·원고 상태·장별 자산 대응·출력 및 검수 상태

생성된 패키지에는 Markdown 기획 파일을 포함하지 않습니다. 실제 배포 전에 주제별 07_review.md에서 검수와 이미지 사용 조건을 확인하세요. 새 출력물은 기본적으로 검수 전 시안이며 자동 게시되지 않습니다.

생성 패키지는 Git에서 기본 제외합니다. 원고·자산 원본은 contents/에 보존됩니다. 저장소 밖 폴더로 출력하려면 scripts/build_cardnews.py에 --output-root를 지정하세요. 생성 패키지를 공유하려면 해당 build 폴더 전체를 전달하면 됩니다.
