# 휴마인 카드뉴스 텍스트·레이아웃 가이드 v0.1

상태: 참고 이미지에 기반한 작업 시안. 공식 브랜드 규정 확정 전.
기준: 사용자가 2026-09-15 제공한 5종 레이아웃이 포함된 스크린샷.
우선순위: 글자의 위치 → 정보 위계 → 공통 여백 → 이미지와 장식.

## 파일

- cardnews.css: 공통 토큰과 5종 카드 구조
- layout-preview.html: 예시 문구를 넣은 5종 미리보기. CSS와 같은 폴더에 두고 브라우저에서 열기
- 이 문서: 유형 선택과 원고 분량 기준

참고 이미지의 다른 회사 로고·문구·이미지는 재사용하지 않았다. HUMINE은 임시 텍스트 표기이며 공식 로고가 아니다.

글꼴은 시스템 한글 글꼴 우선이다. 환경에 따라 줄바꿈이 달라질 수 있으므로 실제 제작에서는 사용 허가가 확인된 글꼴을 고정하고 다시 확인한다.
색상은 위치·가독성 검토용이다. 브랜드 색과 글꼴 확정은 별도 단계로 진행한다.

## 5종 레이아웃

좌표는 1080×1350 원본 캔버스의 왼쪽 위를 기준으로 한다. CSS가 기준 파일이며 값 변경 시 문서와 미리보기 설명도 함께 갱신한다.

| 유형 | 클래스 | 텍스트 기준 | 사용 목적 |
| --- | --- | --- | --- |
| 표지 | card--cover | X=80, 문구 블록 Y=888, 왼쪽 정렬. 보조 문구 뒤 제목. 브랜드는 footer 중앙 | 두 줄 이내 핵심 제목 |
| 전체 그라데이션 | card--gradient | X=80, 제목 Y=776, 왼쪽 정렬 | 배경과 설명을 자연스럽게 연결 |
| 하단 분할 | card--split | 상단 이미지 높이 650, X=80, 제목 Y=740 | 시각 자료와 설명을 명확히 구분 |
| 중앙 오버레이 | card--overlay | 블록 중심 X=540, Y=850, 가운데 정렬 | 짧은 핵심 메시지·전환 장면 |
| CTA | card--cta | 768×744 패널을 캔버스 중앙, 내부 padding 80, 가운데 정렬 | 요약·다음 행동 |

중앙 오버레이는 참고 이미지처럼 가로 중앙에 놓되 세로 중심보다 아래에 배치한다. 중앙으로 옮기려면 --overlay-copy-center 한 곳을 수정한다.
CTA 제목은 56px, 보조 문구는 32px이며 브랜드는 패널 하단에서 80px 위에 둔다.
이 5종은 유형의 수다. 콘텐츠 장수는 주제와 요청에 맞게 정한다.

## 문구 분량

- 표지: 보조 문구 1줄 + 제목 2줄을 기본으로 한다.
- gradient/split: 제목 1~2줄 + 본문 3~4줄 권장. 실제 글꼴로 Y=1160 종료선을 넘지 않는지 확인한다.
- overlay: 제목 1~2줄 + 본문 3줄 정도의 짧은 문구를 권장한다.
- CTA: 제목 2줄 + 보조 문구 1~2줄. 하단 브랜드와 겹치지 않게 한다.
- 줄 수는 권장값이며 글자 수만으로 적합 여부를 확정하지 않는다. 원고를 실제 캔버스에 넣고 확인한다.
- 넘치면 문구를 줄이거나 장을 나눈다. font-size를 임의로 줄이거나 글을 잘라 숨기지 않는다.
- 강제 줄바꿈은 의미 단위로 제한하고, 본문이 충분히 읽히는지 확인한다.

## CSS 관리

- 공통 값은 :root 토큰에서 관리한다. 장마다 padding·글자 크기 숫자를 반복 지정하지 않는다.
- 구조: .humine-card → .card-media / .card-shade / .card-copy / .card-footer.
- CTA는 .cta-panel을 사용한다.
- .card-media에 실제 이미지가 들어가도 .card-copy의 위치는 유지한다.
- 이미지와 텍스트를 분리한다. 최종 한국어 텍스트는 HTML로 배치한다.
- 예외는 명명된 유형이나 토큰으로 표현한다. 미리보기의 --preview-scale은 화면 크기에 맞춰 전체 캔버스를 축소하는 용도이며 출력 레이아웃을 바꾸지 않는다.
- 안내선은 검토용이다. 최종 이미지에는 .show-guides를 적용하지 않는다.

## 검수 및 남은 단계

- 수행: 파일 구조와 HTML/CSS 연결, 5종 클래스·좌표·공통 토큰의 정적 점검.
- 미실시: 브라우저 화면 검수, 실제 원고의 넘침 검수, 확정 글꼴·이미지를 넣은 최종 출력 검수.
- 원인: 자동 브라우저의 로컬 파일 URL 열기가 보안 정책에 의해 차단됨.
- 이 미리보기는 레이아웃 초안이다. PNG 자동 생성 기능은 아직 구현하지 않았다.

최종 제작 전 모든 장의 padding, 텍스트 영역, 한글 줄바꿈, 출처 가독성, 대비, 이미지 해상도와 출력 크기를 확인한다.
