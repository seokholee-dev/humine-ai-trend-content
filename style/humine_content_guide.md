# 휴마인 콘텐츠 가이드 v0.1

## 목적
AI 기술의 변화를 기업 업무와 교육의 언어로 설명한다. 독자는 기업 실무자·팀 리더·HRD 담당자다.
기본 흐름은 Trend → Work → Skill → Education이다. 카드뉴스와 칼럼은 같은 Core Brief를 따른다.

## 문체
- 기본 언어는 한국어다. 본문은 '합니다'체를 기본으로 하며 짧고 구체적으로 쓴다.
- 카드 제목은 간결한 구나 문장으로 쓴다. 같은 묶음 안에서 표현 방식을 통일한다.
- 전문 용어는 처음에 쉬운 설명을 붙인다. 기능 이름만 나열하지 않는다.
- 강한 단정, 과장, 공포를 자극하는 문구와 근거 없는 성과 보장을 피한다.
- 독자가 실제로 할 수 있는 다음 행동으로 끝낸다. 모든 글을 상품 광고로 마무리하지 않는다.

## 내용 전개
1. 무엇이 바뀌었는지 확인된 사실로 소개한다.
2. 왜 중요한지 해석하되 사실과 구분한다.
3. 담당자·입력·과정·산출물·검토 지점을 통해 업무 변화를 설명한다.
4. 업무 변화에서 필요한 역량을 도출한다.
5. 역량을 학습 목표와 실습으로 연결한다.

## 표현 예시 — 실제 제품 주장 아님
| 피할 표현 | 권장 방향 |
| --- | --- |
| AI가 업무를 완벽하게 해결합니다. | 초안 작성에 활용하고, 조건과 결과는 담당자가 검토합니다. |
| 누구나 생산성이 10배 높아집니다. | 어떤 단계가 줄어드는지 설명하고, 효과는 실제 업무에서 측정합니다. |
| 이 기술을 모르면 뒤처집니다. | 이 변화가 관련 업무에 어떤 영향을 주는지 살펴봅니다. |

## 근거와 브랜드
- 사실과 숫자에는 원문 출처 ID를 붙인다. 실제 사례와 가상 업무 시나리오를 구분한다.
- 휴마인의 고객·상품·성과·강사·제휴 정보는 제공되거나 검증된 자료만 사용한다.
- 교육 아이디어는 제안임을 명시한다. 운영 중인 과정처럼 쓰지 않는다.
- 콘텐츠 로고는 사용자 제공 Data Diving 원본(style/assets/datadiving-logo.png)을 사용한다. 임의의 HUMINE 표기를 로고처럼 만들지 않는다. 나머지 색상·글꼴 값은 레이아웃 시안이다.
- 링크가 제공되지 않으면 임의의 문의 링크나 판매 문구를 만들지 않는다.

## 형식별 기준
- 칼럼: 맥락과 적용 조건을 충분히 설명한다.
- 카드뉴스: 장마다 메시지 하나. 정확한 한국어 문구는 이미지와 분리한다.
- 제목·본문 위치와 여백은 humine_visual_guide.md와 cardnews.css를 따른다.
- 5종 레이아웃은 유형이며 전체 장수를 제한하지 않는다.

## 이번 구축 범위
파일 구조·양식·입출력 연결을 우선 완성한다. 줄바꿈·넘침 검수는 사용자 요청에 따라 후속 단계로 보류한다.
보류 항목을 검수 완료로 표시하지 않으며 실제 콘텐츠 제작 시 별도 상태로 관리한다.
