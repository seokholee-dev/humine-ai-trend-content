# 카드뉴스 스타일

사용자가 제공한 5종 참고 레이아웃을 바탕으로 제목·본문 위치와 공통 여백을 먼저 정의한 시안입니다.

- [humine_visual_guide.md](humine_visual_guide.md): 위치·분량·유형 선택과 검수 기준
- [cardnews.css](cardnews.css): 공통 padding·gap·글자 크기와 5종 카드 레이아웃
- [layout-preview.html](layout-preview.html): 예시 문구로 확인하는 5종 미리보기

CSS와 HTML을 같은 폴더에 내려받고 HTML을 브라우저에서 열면 됩니다. GitHub 파일 화면은 HTML 코드를 표시합니다.

기준: 1080×1350, 좌우 여백 80px, 본문 제목 60px, 본문 40px. 표지와 CTA는 역할별 크기를 따릅니다.
cover / gradient / split / overlay / cta 유형을 사용하며, 5종이 전체 장수를 뜻하지는 않습니다.

배경과 문구·색상·글꼴은 검토용입니다. 공식 로고와 브랜드 가이드는 추후 반영합니다.
현재 자동 이미지 출력 기능과 실제 브라우저 화면 검수는 완료하지 않았습니다. 세부 검수 상태는 가이드에 기록합니다.
