# Humaiin AI Trend Content

최신 AI 트렌드를 기업의 업무·역량·교육으로 연결하는 콘텐츠 작업공간입니다.

전체 운영 방향과 제작 순서, 현재 완료 범위 및 후속 계획은 [제작·운영 기획안](PROJECT_PLAN.md)에서 확인할 수 있습니다.

## VS Code에서 이렇게 요청하세요

> 최근 7일 AI 트렌드에서 주제를 골라 칼럼과 8장 카드뉴스를 만들어줘. 원고에 맞는 구체적인 업무 장면과 도식을 기획하고, 내장 이미지 도구로 생성·수정한 뒤 HTML로 합성해줘.

Codex가 조사 → 공통 기획 → 칼럼 작성·검수 → 칼럼을 카드뉴스로 요약 → 이미지 기획·생성 → 합성·검수를 진행합니다. 원하는 스타일이나 수정 방향은 이 대화에 짧게 말씀하시면 됩니다. 최종 카드 PNG가 필요하면 출력도 요청하세요.

별도 유료 API 호출 코드는 제거했습니다. API 키 설정은 필요하지 않습니다. 내장 도구의 제공 여부·이용 한도는 현재 세션에 따르며, 별도 결제나 과금이 필요한 작업으로 자동 전환하지 않습니다.

## 반복 제작용 폴더 구조

```text
contents/날짜-주제/              # 기획·출처·원고·검수와 이미지 원본
output/날짜-주제/build-실행시각/  # 원고와 분리된 결과물
  index.html                    # 전체 보기
  html/                         # 장별 HTML
  png/                          # PNG 출력 요청 시에만 생성
  assets/                       # 실제 사용한 배경 원본
  manifest.json                 # 원고 해시·장별 이미지 연결·출력 상태
```

다른 주제를 추가하거나 같은 주제를 수정해 출력해도 이전 실행 결과는 보존됩니다. 저장소 밖 출력 위치는 `--output-root`로 지정합니다. 이 구조는 반복 제작을 위한 기반이며 상용 배포 전 시각 검수와 자산 사용 조건 확인은 별도입니다.
