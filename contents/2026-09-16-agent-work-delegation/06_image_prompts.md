## 공통 아트 디렉션
- 색상은 기존 남색·백색·청색·호박색 시안을 이어간다. 통일감은 색·광원·선 굵기로 맞추고 소재·시점·행동은 바꾼다.
- 생성 장면은 구체적인 업무를 표현하는 편집 일러스트로 제작한다. 실제 고객·실제 도입 장면처럼 제시하지 않는다.
- 정확한 한국어 제목·본문·도식 라벨·로고는 별도 합성한다. 생성 그림에 긴 글을 맡기지 않는다.

- 현재 CSS의 split 영역은 1080×650이다. 여기에 들어가는 자료는 가로로 제작하고, 다른 장의 세로 배경과 구도를 분리한다.
- overlay는 이미지 위에 어두운 덮개가 있다. 중요한 도형은 크고 명확하게 만든다. CTA 중앙은 패널에 가려지므로 중요한 정보는 배경에 두지 않는다.

## 확보와 제작의 원칙
외부 자료가 유용하고 의도한 이용 조건이 확인되면 실제 제작 단계에서 확보·활용한다. 상세 절차는 ../../prompts/visual_planner.md를 따른다. 2장 후보의 원본·조건·크레딧은 05_sources.md의 I1에서 관리한다. 현재 채널은 미정이며 자료를 사용할 수 있다고 판정하지 않았다. HTML 내장과 assets/ 원본 전달까지 허용되지 않으면 기존 자체 제작 대안을 사용한다.

공식 자료는 2장에서 우선 검토한다. 검색 결과 썸네일을 그대로 쓰지 않고 원문 이미지·제작자·재사용 조건·출처 표기 방식을 확인한다. 확인하지 못하면 사용하지 않고 해당 장의 자체 제작 대안으로 진행한다. 유료 스톡·별도 API는 사용하지 않는다. 확보한 자료의 출처는 05_sources.md에 이미지 자산용 ID로 추가한다. 현재는 후보 경로만 지정한 상태이며 확보 완료가 아니다.

도식은 편집 가능한 HTML/CSS로 만들고 실제 렌더링해 PNG로 저장한 뒤 기존 카드의 배경 입력으로 연결한다. 현재 합성 코드는 PNG·JPEG·WebP 입력을 지원한다. 도식 구현·렌더링은 다음 제작 단계이며 이번에 새 렌더러나 CSS를 수정하지 않는다.

## CSS·시각 검수
- 레이아웃 위치·로고 참조: 기존 CSS 사용.
- 이미지 내용·구도: 도구가 반환한 실제 이미지 2종을 확인. 상단의 업무/승인 장면과 하단 여백, 문자·제품 UI 부재 확인. 칼럼에는 생성 일러스트 표기. 카드의 최종 대비·잘림 판정은 미실시.
- padding·gap의 화면상 일치, 글꼴 로딩, 출처 가독성, 대비, 실제 한글 줄바꿈·넘침: 미실시/보류.
- 최종 카드 PNG: 별도 요청·렌더링 단계. 현재 범위는 이미지 생성과 HTML 합성.
