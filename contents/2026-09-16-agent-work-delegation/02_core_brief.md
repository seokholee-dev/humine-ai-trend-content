## 핵심 메시지
AI 에이전트를 업무에 연결하려면 사람이 입력 자료, 허용 행동, 승인 조건, 완료 기준을 구체적으로 설계하는 역량을 갖춰야 한다.

## Why now — 왜 지금 주목하는가?
- 사실: 위 발표·사례가 조사 기간 안에 공개됐다.
- Humaiin의 해석: AI 교육에서 질문 작성과 함께 업무 위임의 조건을 다룰 실무적 계기가 생겼다. 시장 전체의 성숙이나 즉시 도입 가능성을 뜻하지 않는다.

## Work — 반품 요청의 처리 초안
- 사례 구분: 가상 활용 예시. 특정 제품의 실행 검증 사례가 아님.
- 담당자·입력: 고객지원 담당자, 식별정보를 제거한 문의, 주문 정보, 최신 반품 규정.
- 기존 과정 → 제안 과정: 담당자가 자료를 모아 초안을 작성 → AI가 허용 자료를 대조해 처리 초안과 근거를 제출하고 담당자가 예외를 판단.
- 산출물: 처리 제안, 적용 규정, 누락 자료, 승인 요청 사유.
- 사람 검토: 규정 예외, 정보 불일치, 환불 확정 등 지정된 행동.
- 조건: 읽기 권한과 변경 권한을 구분하고 시험 단계에서는 실제 환불을 실행하지 않음.

- 칼럼: 반품 업무 질문 → 이번 주 발표 → 위임 명세 → 가상 반품 업무 → 평가 실습 → 다음 행동.
- 카드: 표지 → 업무 특화 → 승인 설계의 이유 → 업무 분해 → 가상 반품 → 필요한 역량 → 교육 제안 → 다음 행동.
- 다음 행동: 팀의 반복 업무 하나에 입력·허용 행동·승인 조건·완료 기준을 적는다.
