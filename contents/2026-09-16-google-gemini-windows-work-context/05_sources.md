## 외부 이미지 이용 기록
### I1 — Google Gemini Windows 공식 발표 이미지 후보 / 02장
- 권리자·제작자: 발표 페이지 운영자는 Google. 해당 시각 자산의 개별 제작자·권리 관계는 미확인.
- 원문 페이지: S2. 원본 후보는 페이지 내 Image 링크(storage.googleapis.com); 다운로드하지 않음.
- 이용 조건 확인 URL: https://about.google/brand-resource-center/guidance/
- 확인일: 2026-09-16
- 근거 요약: 정보 전달 목적의 텍스트 언급·링크와 표준 교육 자료의 변경 없는 화면 사용 안내 확인. 이번 기업 홍보 가능성이 있는 합성물과 원본 사본 배포까지 허용한다는 개별 근거는 확보하지 못함.
- 예정 용도: 기업 업무·교육 트렌드 설명 HTML, 향후 SNS 활용 가능성. 실제 외부 게시 없음.
- 상업적 이용·편집·원본 재배포·HTML 내장·assets 전달: 이번 후보에 대한 허용 범위 미확인.
- 인물·상표 조건: 공식 제휴·보증으로 보이지 않도록 할 것. 후보 사용 시 추가 검토 필요.
- 권리 판정: 사용 제외 — 이번 제작에서는 사용 조건을 확정하지 못해 미확인 상태의 원본을 포함하지 않음.
- 실제 파일: 미확보. 필수 크레딧: 사용하지 않아 해당 없음.
- 대체 자산: 단축키를 보여주는 자체 제작 개념도. 제품 UI·로고·공식 발표 이미지 모사 없음.

## 실제 사용 자산
- 업무 장면 3종: 내장 이미지 도구로 제작·저장한 가상 장면. 실제 인물·실제 기업 사례를 표현하지 않음.
- 도식 5종: 문서에 기록한 개념으로 직접 제작. 외부 이미지·아이콘·폰트 파일을 복사하지 않음.
- Data Diving 로고: 기존 사용자 제공 자산. 현재 저장소의 적용 방식 유지.
- 생성 및 자체 제작 자산도 모든 권리 문제가 없다고 보증하는 것은 아님. 새로운 이용 목적·채널은 배포 시 확인.
